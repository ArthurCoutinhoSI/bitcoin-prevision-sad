# Artifact Contract

**Feature**: `001-bitcoin-forecast-dashboard` | **Version**: 1 | **Date**: 2026-11-08

Artifacts are local, generated files. They are excluded from version control and may be regenerated
by running the training command.

## Directory Layout

```text
artifacts/
├── model.pkl
├── evaluation.json
└── validation_predictions.csv
```

## `model.pkl`

**Format**: Python pickle (highest available protocol), written atomically to a temporary file in
the same directory and then renamed.

**Contents**: A dictionary with the following required keys.

| Key | Type | Rules |
|-----|------|-------|
| `artifact_version` | Integer | Must equal `1` |
| `created_at` | String | ISO-8601 timestamp |
| `model` | statsmodels ARIMA result | Fitted production model |
| `model_name` | String | `ARIMA` |
| `order` | List[Integer] | Three non-negative integers `[p, d, q]` |
| `target` | String | `close_USD` |
| `horizon_days` | Integer | `1` |
| `evaluation_training_range` | List[String] | `[start_date, end_date]`, ISO `YYYY-MM-DD` |
| `validation_range` | List[String] | `[start_date, end_date]`, ISO `YYYY-MM-DD` |
| `production_training_range` | List[String] | `[start_date, end_date]`, ISO `YYYY-MM-DD` |
| `last_observed_date` | String | ISO `YYYY-MM-DD` |
| `next_forecast_date` | String | ISO `YYYY-MM-DD`; one day after `last_observed_date` |
| `dataset_fingerprint` | String | `sha256:<hex>` of the source CSV |
| `preprocessing` | Object | Preprocessing summary from `data-model.md` |
| `evaluation` | Object | Evaluation report from `data-model.md` |

**Load validation**:

1. The file exists and can be unpickled.
2. The root object is a dictionary.
3. `artifact_version` equals the supported version.
4. All required keys exist and have the expected types.
5. `order` has exactly three non-negative integers.
6. The artifact fingerprint matches the source dataset used for inference.
7. The fitted model can produce a finite one-step forecast.

Any failure is an incompatible artifact. The CLI exits with code `4`; the dashboard shows an
actionable error and no forecast.

**Security**: Only artifacts generated by this project are trusted. Pickle can execute code on
load; the application must never load an artifact supplied by an untrusted source. The dashboard
and CLI must document this restriction.

## `evaluation.json`

**Format**: UTF-8 JSON.

```json
{
  "generated_at": "2026-11-08T12:00:00Z",
  "dataset_fingerprint": "sha256:...",
  "split": {
    "train_range": ["2018-05-07", "2020-07-14"],
    "validation_range": ["2020-07-15", "2021-01-30"],
    "train_count": 800,
    "validation_count": 200,
    "split_method": "chronological"
  },
  "model": {
    "name": "ARIMA",
    "order": [1, 1, 1],
    "selection_method": "AIC",
    "candidate_grid": {"p": [0, 1, 2], "d": [0, 1], "q": [0, 1, 2]},
    "aic": 0.0
  },
  "model_metrics": {"mae": 0.0, "mse": 0.0, "rmse": 0.0, "r2": 0.0, "observation_count": 200},
  "baseline_metrics": {"mae": 0.0, "mse": 0.0, "rmse": 0.0, "r2": 0.0, "observation_count": 200},
  "outperforms_baseline_rmse": false,
  "preprocessing": {
    "source_count": 1000,
    "accepted_count": 1000,
    "rejected_count": 0,
    "duplicates_removed": 0,
    "missing_values_imputed": 0,
    "rows_excluded_without_prior_value": 0,
    "date_range": ["2018-05-07", "2021-01-30"],
    "actions": []
  },
  "limitations": [
    "Univariate ARIMA using only the USD closing price",
    "Historical dataset covers 2018-05-07 through 2021-01-30",
    "Forecasts are estimates and are not financial advice"
  ]
}
```

**Rules**:

- Metric values are finite numbers, except `r2`, which may be `null` when the validation actuals
  have zero variance.
- `train_range` ends before `validation_range` starts.
- `model_metrics` and `baseline_metrics` use the same observation count.
- `outperforms_baseline_rmse` is `model_metrics.rmse < baseline_metrics.rmse`.
- The file must not contain secrets or personal data.

## `validation_predictions.csv`

**Format**: UTF-8 CSV with a header.

| Column | Type | Rules |
|--------|------|-------|
| `date` | Date | ISO `YYYY-MM-DD` |
| `actual_close` | Float | Positive |
| `model_prediction` | Float | Finite |
| `baseline_prediction` | Float | Finite |

**Rules**:

- Row count equals `validation_count`.
- Dates are unique and in ascending order.
- The first row's actual close is the last training actual close used by the baseline.
- The file is for visualization and audit; it is not an input to model training.

## Atomicity and Failure Handling

- Write each artifact to a temporary file and rename it into place after a successful write.
- Do not leave partial artifacts after a failed training run.
- If any artifact cannot be written, the command exits with code `4`.
- The dashboard treats a partially present artifact set as `invalid_artifacts` and shows an
  actionable message.
